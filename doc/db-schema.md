# Database Schema

A snapshot of the current PostgreSQL schema in Prisma-style notation. It is generated by hand from the TypeORM entities in `backend/src/modules/**/entities/*.entity.ts`, so the entities remain the source of truth and this file is a readable reference. It is not a working `schema.prisma`.

Notation:

- **Single schema (`public`).** `@@map` gives the table name. Columns are the snake_case form of each field (`academicYearId` → `academic_year_id`).
- **All `id` and `*Id` fields are `uuid`.** Primary keys are generated uuids.
- **`// tenanted` models extend `OrgScopedEntity`.** They carry `orgId` with an FK to `Organization` that cascades on delete, and are protected by the RLS policy `org_isolation`. Per-org uniqueness always includes `orgId`.
- **Back-relations.** Only the ones the entities declare (`OneToMany`/`OneToOne`) are listed. The implicit `Organization` back-relations on tenanted models are omitted.
- **Enums.** Enums marked `// pg enum` are native Postgres enums. All the others are `varchar` columns whose values are checked in code.
- **Soft delete.** `deletedAt` marks a soft-deleted row (TypeORM `@DeleteDateColumn`).
- The sample modules `cats`, `tasks` and `products` are left out.

model Organization {
  id          String             @id @default(uuid())
  name        String
  slug        String             @unique // subdomain / x-tenant-id
  domain      String?            @unique // custom domain
  status      OrganizationStatus @default(active)
  createdAt   DateTime           @default(now())
  updatedAt   DateTime           @updatedAt

  memberships Membership[]

  @@map("organizations")
}

model User {
  id              String     @id @default(uuid())
  email           String     @unique
  password        String       // select: false
  username        String?      @unique @db.VarChar(60)

  createdAt       DateTime   @default(now())
  updatedAt       DateTime   @updatedAt

  @@map("users")
